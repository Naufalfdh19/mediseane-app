# 🌀 Montelukast - Online Pharmacy Management System
Montelukast is a high-performance, scalable e-pharmacy platform designed to handle online medicine orders with precision and reliability. Built with a modern backend architecture, it ensures seamless inventory management and asynchronous order processing.

The project is named Montelukast—symbolizing a system that helps users "breathe easier" when managing their healthcare needs.

## 🚀 Tech Stack
This project leverages a cutting-edge stack to ensure data integrity and system speed:
1. Backend: Go (Golang) – Chosen for its superior concurrency and execution speed.
2. Message Broker: RabbitMQ – For asynchronous tasks (e.g., order queuing, email notifications).
3. Primary Database: PostgreSQL – Relational database for robust transactional data.
4. Caching & Session: Redis – For high-speed data retrieval and real-time inventory locking.
5. Containerization: Docker & Docker Compose – Ensuring a consistent development and deployment environment.
